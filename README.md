# Customer Segmentation Analysis Project

This project focuses on analyzing customer data to identify meaningful customer segments and understand different purchasing patterns and behaviors. The analysis was performed using data analysis techniques and visualized through an interactive **Power BI dashboard**.

The project helps transform raw customer data into meaningful insights that can support better business decisions, targeted marketing strategies, and improved customer understanding.

### Key Objectives

* Analyze customer demographics and behavior.
* Identify different customer segments based on available data.
* Discover patterns and trends in customer activity.
* Create interactive and insightful visualizations using Power BI.
* Generate data-driven insights to support business decision-making.

### Tools & Technologies

* **Power BI**
* **Data Analysis**
* **Data Cleaning**
* **Data Visualization**

This project demonstrates my ability to work with customer data, perform analysis, and present insights through interactive dashboards.
